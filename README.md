# 🌿 Yeeps Staff Hub

Welcome to the Yeeps Staff Hub!

A community-made website designed to organize and manage staff information, player searches, and roles within the Yeeps community.

## ✨ About

This project aims to provide a clean, easy-to-use dashboard with a Yeeps-inspired design.

## 🚀 Features

- Staff role organization
- Player search
- Staff information management
- Dark mode and light mode
- Custom Yeeps-inspired design
- Role logos and graphics

## 🎨 Design

The website includes two visual themes:

- **Dark Mode** – A darker, modern interface.
- **Light Mode** – A brighter, colorful interface.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
